## 计算公式

- `CPI = C / N`
- `CPU 时间 = C × 100 ns`
- `相对单周期加速比 = 单周期 CPU 时间 / 当前版本 CPU 时间`
- `预测收益 = 关闭预测流水线时间 / 开启预测流水线时间`
