# RV32I 16 条指令控制表

| 指令 | 匹配 | rs1 | rs2 | 立即数 | ALU | 存储器 | 写回 | 分支 |
|---|---|:---:|:---:|---|---|---|---|---|
| add | 0110011/000/0000000 | ✓ | ✓ | - | ADD | - | ALU | - |
| sub | 0110011/000/0100000 | ✓ | ✓ | - | SUB | - | ALU | - |
| xor | 0110011/100/0000000 | ✓ | ✓ | - | XOR | - | ALU | - |
| and | 0110011/111/0000000 | ✓ | ✓ | - | AND | - | ALU | - |
| or | 0110011/110/0000000 | ✓ | ✓ | - | OR | - | ALU | - |
| addi | 0010011/000 | ✓ | - | I | ADD | - | ALU | - |
| ori | 0010011/110 | ✓ | - | I | OR | - | ALU | - |
| andi | 0010011/111 | ✓ | - | I | AND | - | ALU | - |
| lui | 0110111 | - | - | U | - | - | IMM | - |
| lw | 0000011/010 | ✓ | - | I | ADD | 读32位 | MEM | - |
| sw | 0100011/010 | ✓ | ✓ | S | ADD | 写32位 | - | - |
| beq | 1100011/000 | ✓ | ✓ | B | - | - | - | 相等 |
| bne | 1100011/001 | ✓ | ✓ | B | - | - | - | 不等 |
| blt | 1100011/100 | ✓ | ✓ | B | - | - | - | 有符号小于 |
| bge | 1100011/101 | ✓ | ✓ | B | - | - | - | 有符号大于等于 |
| jal | 1101111 | - | - | J | - | - | PC+4 | 无条件 |
