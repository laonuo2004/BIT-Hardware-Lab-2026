## 查看与下载

获得仓库访问权限后，可直接浏览文件，或通过 Code → Download ZIP 下载全部资料，也可以使用 Git 克隆仓库。

往年项目以普通文件保存，无需额外下载子模块。原作者、来源链接和下载时的提交号见往年项目目录中的导读与下载清单。旧项目的工程环境和实验要求可能与今年不同。

本仓库仅供小组校内学习协作，保持私有。课程资料请勿外传；往年项目保留原作者署名与许可证，其内容不代表本组已完成的实验成果。
